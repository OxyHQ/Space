# Oxy Space

Workspace for docs, databases, and AI, by [Oxy](https://oxy.so).

<Badge variant="success">App</Badge> <Badge>SaaS</Badge>

**Live:** [space.oxy.so](https://space.oxy.so)

## What it is

Oxy Space is a Notion-like workspace surface running on the Oxy ecosystem. Today, the codebase is mid-pivot from a legacy AI chat product — Phase 0 has stripped the visible chat UI, and pages, blocks, databases, real-time collab, and the native AI hub land in subsequent phases.

Surfaces:

- **Expo client** — web + iOS + Android (`apps/app`, built with Expo 55, React Native 0.83, NativeWind, expo-router)
- **Express API** — TypeScript backend (`apps/api`, MongoDB, Redis/Valkey, Socket.IO)

## Monorepo layout

```
apps/
  app/    @oxyspace/app    Expo cross-platform client (web + iOS + Android)
  api/    @oxyspace/api    Express backend
sst.config.ts              SST infra: DO App Platform, DO Spaces, Cloudflare
```

## Stack

| Layer | Technology |
|-------|------------|
| Frontend | Expo 55, React Native 0.83, React 19, NativeWind, Reanimated v4, Zustand, TanStack Query, expo-router |
| Backend | Express, TypeScript, MongoDB (Mongoose, shared `db-oxy` cluster), Socket.IO, Redis (Valkey) |
| Auth | `@oxyhq/services` (web + native), `@oxyhq/core` (API) |
| Internal AI | Internal-only provider routing (Phase 5) — never exposed to end users |
| Infra | SST 4.x on DigitalOcean App Platform + Spaces, fronted by Cloudflare |

## Install

Clone and install with `bun` (this is a bun workspace; do not use npm or yarn):

```sh
git clone https://github.com/OxyHQ/Clarity.git
cd Clarity
bun install
```

Workspaces:

- `apps/api` (`@oxyspace/api`)
- `apps/app` (`@oxyspace/app`)

## Quick start

```sh
# Backend (port 4001)
bun run dev:api

# Frontend (Expo, web + tunnel)
bun run dev:app
```

The API expects a `.env` in `apps/api/` with MongoDB, Redis, and Oxy auth configured. See `apps/api/example.env`.
