# Oxy Station

Oxy Station is an Expo and Express workspace for pages, blocks, typed
databases, comments, sharing, notifications, and real-time collaboration.

<Badge variant="success">App</Badge> <Badge>Workspace</Badge>

## Architecture

- `apps/app` — Expo app for web, iOS, and Android.
- `apps/api` — Express API with PostgreSQL/Drizzle and Socket.IO.
- `@oxyhq/services` and `@oxyhq/core` — Oxy session identity.

Station is PostgreSQL-only. It contains no provider adapters, provider-key
store, model router, or inference endpoint. Agent flows belong to Alia and
reach inference through Oxy and Kaana. Provider credentials live only in
Kaana's encrypted PostgreSQL store.

## Start locally

```sh
bun install
cp apps/api/.env.example apps/api/.env
cp apps/app/.env.example apps/app/.env
bun run dev:api
bun run dev:app
```

The API needs `DATABASE_URL`; the app needs `EXPO_PUBLIC_API_URL`.
